# neolesk is positioned as a collaborative, agent-ready editor

The README opens with "A modern diagram editor powered by Kroki". After this work
most diagrams never reach Kroki, and the product gains shared sessions and agent
control. We decided to lead with collaboration and agent control, and to describe
local rendering as how it works rather than what it is for.

Kroki remains credited as the component that draws the 14 languages with no
browser renderer, and as the fallback for the rest.

## Consequences

- This puts the newest and least proven part of the product — sessions on
  v0.1.0 celld — at the front of how neolesk is described. That was chosen
  knowingly over leading with the local-first privacy story, which is the more
  finished half.
